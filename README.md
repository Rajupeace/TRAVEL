# SRIVORATECH TRAVELS — Premium Bus Travel Booking

A modern, high-performance bus booking web application featuring a full-page scroll-driven bus animation, interactive 2+2 seat selection, live PNR tracking, dynamic route searching, and glassmorphic dark design.

## Features
- 🚌 **Full-Page Scroll Animation**: Background bus animation powered by 300 frames mapped to scroll position.
- 🎫 **Search & Booking**: Filter by origin, destination, date, and passenger count.
- 💺 **Interactive Seat Layout**: Pick seats in real-time with instant price calculations.
- 📍 **Live Bus Tracking**: Real-time route timeline, speed, ETA, and distance statistics via PNR lookup.
- ✨ **Glassmorphism UI**: Backdrop blur, custom neon glow effects, and modern typography.
- 📱 **Mobile Responsive**: Custom mobile navigation drawer and stacked layout targets.
